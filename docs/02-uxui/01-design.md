## UI 규칙

토큰 원본은 [tokens.css](../../frontend/css/tokens.css)이며, 알파 1 단색 표면(backdrop blur 미사용), 카드 상단 밝은 inset·낮은 외곽 그림자, 입력·세그먼트 트랙 얕은 inset을 적용한다.

- 작업(기본)·맥락·기억 독립 페이지 구성(데스크톱 2열, 모바일 1열). 장식 구체·동심원·그라데이션·홍보 문구 제외, Orb는 작은 상태 표시로 제한.
- 색상: blue=주 동작(화면 5% 미만), violet=학습·제안, error=오류(색만으로 상태 전달 금지).
- 서체: 제목 IBM Plex Sans KR 700, 본문 Pretendard Variable 400–600, Mono는 wordmark·실시간 지표 전용.
- 모션·조작: 버튼 press·상태 crossfade만 사용(reduced motion은 opacity 120ms 이하), 포커스 표시·터치 영역 44px+ 유지.
- 버튼·알림: 주 버튼(solid blue·한국어 동사), 보조 버튼(밝은 불투명 표면·선), 삭제(error 텍스트). 성공 토스트는 생략하고 오류·비동기 결과는 고정 안내.

## 작업 흐름과 모바일

- 활동 선택은 작업·맥락 화면 간 동기화한다. 좌우 손짓(학습)과 손바닥·원형(확인) 그룹을 분리 표기하고, 행동 연결 후 같은 몸짓 재입력 버튼과 제안 승인 카드를 안내한다.
- 모바일은 헤더 동작을 줄바꿈하고 학습·행동·제안을 카메라보다 먼저 배치한다. 본문 14px+, 보조 12px+, select 16px, 터치 44px+, 대화상자 안전 영역 내 스크롤, 실행 결과 닫기·시뮬레이션 표시를 유지한다.

## 플로팅 필 탭 바

하단 메뉴와 선택 배경은 `999px` 필 곡률과 브랜드 색상을 사용하며 화면 가장자리·안전 영역과 띄워 본문·포커스 가림을 방지한다(본문 하단 여백 확보, 캡처 시 하단 중앙 고정). hash 링크로 작업(입력·행동·제안·카메라)·맥락(활동·해석·개인정보)·기억(지표·기억·이벤트·감사 로그)을 전환하며 제목·설명을 갱신하고 페이지 시작으로 이동한다.

## 단계별 노출과 복귀

- 작업 화면은 몸짓 선택 → 행동 연결 카드(관찰·반복) → 승인 카드(대기 제안) 순으로 노출하고, 확인 몸짓은 제안·실행 결과가 있을 때만 표시한다.
- 카메라는 기본 접힌 보조 영역에 두고 제목에 상태(켜짐·꺼짐·오류)를 표시하며 접어도 세션을 유지한다.
- 빈 맥락·기억에는 학습 링크를, 승인 후에는 재입력을, 거절 후에는 다른 행동 연결을 안내한다. UI 문구는 한국어로 통일(앱 이름·API 값 유지)하고 단계 전환 시 스크롤·포커스를 이동하며, 초기 연결 실패 재시도 시 설정 복구 후 대시보드를 다시 불러온다.
